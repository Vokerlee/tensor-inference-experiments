# Matched native plane-rounding and retention evidence

Three complete, clean-source reports preserve one reused discovery input,
four reused follow-up inputs and the encoded-source capacity ledger. Discovery
modifies all25 eligible convolutions with software tile batch64; follow-up
modifies24 convolutions with at least128 output channels, using batch256.
These source states were captured in earlier studies, not new independent
prompts or an untouched population-level test set.

Nearest, rank1 completed-proxy and causal packed-shift policies share each
native INT4/INT8 grid and retire the authoritative returned exponents. Every
original decoder replay is bit-exact against its capture. All final raw/image
outputs, prepared coefficients, packed metadata, source identities, native
binary SHA256/compiler metadata and logs are retained. No CUDA time is used
as target-chip latency or energy.

`index.json` contains three complete report payloads; `evidence.json` maps all30
logical attachments to byte-exact containers, with duplicate storage shared.
The mapping report normalizes only its machine-local profile path; its original
JSON remains an explicit byte-exact attachment. The encoded-retention variants
are capacity proposals, not proven port schedules or energy measurements.

```sh
python scripts/archive_selective_reference_evidence.py --verify --output <archive>
python scripts/archive_selective_reference_evidence.py --output <archive> --restore <new-directory>
```

The independent `scripts/report_winograd.py` audit checks every aggregate and
per-input output metric before regenerating tables. A recursive checkout
restores the code pins; original inputs/checkpoints are hash-identified in the
complete reports and regenerated through the existing capture workflow.
