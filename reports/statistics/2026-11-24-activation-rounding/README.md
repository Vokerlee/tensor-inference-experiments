# Activation rounding: preserved evidence

Five JSON records and 631 byte-exact attachments are indexed by `index.json`
and `evidence.json`. Run `scripts/archive_selective_reference_evidence.py
--verify --output reports/statistics/2026-11-24-activation-rounding` to check
both source JSON and attachment hashes.

The first operator campaign allowed an upward alternative even at an exactly
representable grid point. It remains a **preliminary wider-feasible-set variant**;
the adjacent-operator campaign fixes this by requiring floor and ceil. Do not
pool these implementations. The preliminary weight-only sketch has incomplete
historical environment metadata; its preserved script is historical evidence,
not a portable regeneration entry point.

Operator comparisons reuse previously captured operands. The two full-model
campaigns reuse the same ten Imagenette images; they are not twenty independent
images. All quantized tensors feed subsequent model operations. The attention
campaign includes matched split-Q/K/V BF16 controls. No GPU execution time here
estimates target accelerator time or energy.

The frozen-feature CIFAR100 task uses separate evidence, not this archive.
Original local absolute paths in raw JSON are provenance; indexed relative
archive paths resolve the preserved bytes after a fresh clone.
