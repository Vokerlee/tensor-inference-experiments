# DiT-XL/2,256px

Historical class-conditioned diffusion-transformer control. Retained paired
activation-representation and generation diagnostics are described in the
[activation report](../../reports/2026-11-22-activation-representations.md) and
[reproduction instructions](../../docs/reproduce-activation-pilots.md).

The [complete matrix-work profile](matrix-work-2026-11-22.json) preserves its
original inventory, scope and version fields. It counts synthetic denoiser
work; it does not establish generation quality or energy. The separate paired
generation report records checkpoint, class/noise/step settings and numerical
metrics. Modern text-conditioned SANA-Sprint is a separate workload.

[Preserved scientific statistics](../../reports/statistics/2026-11-23/models.md#dit-xl2-256)
include the complete dated records available at this snapshot, including earlier
exploratory runs. Consult their original conditions and source status.
